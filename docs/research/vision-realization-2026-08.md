# 愿景实现评估:三级命题对账与实现阶梯(2026-08-29)

> **研究评估,不是合同**——与 docs/12–18 冲突时以 12–18 为准。本文把 [`agent-landscape-2026-08`](agent-landscape-2026-08/README.md) 的三级命题(02 §4)对账到 1.1.0 线收口时的实际状态;可执行门槛的**权威载体**是 docs/17 §16.9(冻结于同日),本文承载分析全文与推理过程。评估基线:commit `f651cd8`(G16 完成、verify:matrix 双腿全绿、docs/18 RCP-1、G13–G17 休眠 spec 齐备)。

## 1. 愿景坐标(档案权威表述的压缩)

谱系上六系统(Grok/Kimi/Manus/Danus/OpenManus/Magentic)在四个器官——持久共享状态、产出者≠判定者、加载式工具、预算机制——独立趋同,且**没有任何一支演化出持久化副作用协议**(02 §2.1 的谱系空位)。Ordarium 的生态位即补此空位:把外部副作用本身做成持久、可撤销、带授权证据的状态("状态离开上下文窗口"轴的下一步)。两项目分工由 [宪章](agent-landscape-2026-08/05-palimpsest-charter.md) 固定:Ordarium = 宿主中立的证据型时间线引擎;Palimpsest = 管理层参考实现 + 头号证明场;互相禁止伸手(Palimpsest 不自写 CAS/fence/锁,Ordarium 不碰编排/消息)。

路径四步(第二真实宿主 → conformance 被外部引用 → 公开恢复案例 → 第三方引用)一步未走,与档案自己的预言一致:六系统全垂直整合、无动机采纳外部内核,缝隙在长尾(无厂商资源的 harness 作者、跨厂商组合、被事故教育的团队)。但 1.1.0 把**出发条件**建齐:版本锚定发布线就绪(push/tag/Release 由用户执行)、docs/18 发布沟通纪律("标准"的"话")、兼容登记(机器校验的"层")、休眠 spec 冻结(对消费者的可信机制:触发即按 spec 实施、无需重新设计)。

## 4. 实现阶梯(按依赖排序,每步可证伪)

1. **用户交接项**:git push + `ordarium-v1.1.0` tag + GitHub Release(五 tarball)——命题三最小公开前提,并使 origin 对齐、根除双检出漂移(2026-08-29 的姊妹检出分叉即由此机制产生,已用 cherry-pick 收敛)。
2. **Palimpsest 焊缝**(姊妹仓,活跃):`OPERATION_UNCERTAIN` 接缝 + state kind 迁移 → 闭合①;首个真实恢复案例成文 → 闭合②。
3. **触发连锁预测**:①的实施预期同时构成 G14(跨宿主查看管理型 state)与 G17(Palimpsest 失效传播迁移到内核 refs)的最可能下一触发源——两个休眠 Goal 都可能由同一次迁移唤醒。
